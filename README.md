# Переговоры — учебный тренажёр (MVP)

Браузерный тренажёр по курсу **«Ведение переговоров»**: студент общается с ИИ-собеседником, отрабатывает конфликты, защиту границ и рациональные переговоры, ведёт заметки и по запросу получает подсказки и разбор.

**Принцип:** сначала простое работающее приложение и проверенные данные, затем — QLoRA только если сравнение покажет улучшение. Не строим платформу ради платформы.

## Что зафиксировано

- **200 НОВЫХ кейсов**, прежнюю B01 генерируем заново, без миграций;
- **8 партий × 25 кейсов**: в каждой 10 × `MODEL_MANIPULATOR`, 10 × `MODEL_DEFENDER`, 5 × `MODEL_NEGOTIATOR`;
- итого **80 (40%) / 80 (40%) / 40 (20%)**;
- отдельная LLM генерирует кейсы **офлайн**; во время игры модель **играет роль**;
- проверку качества датасета осуществляет **независимый LLM-валидатор**, затем программа проверяет JSON Schema;
- в MVP играем по заранее принятым кейсам; не генерируем новый мир на каждом ходе;
- подсказки и учебная оценка отделены от ролевых реплик;
- сложность: `easy`, `medium`, `hard`, `extra_hard`, `impossible`; последняя означает невозможность определённого результата, а не бесконечную бессмысленную борьбу.

## Следующее действие

Дать валидатору ссылку на репозиторий и документ `prompts/VALIDATOR_HANDOFF.md`. Он должен проверить структуру, затем составить **новый активационный промпт генератора** для партий по 25, не начиная генерацию без подтверждения.

Статус: **архитектура и контракт зафиксированы; веб-приложение и обучение ещё не реализованы.**
