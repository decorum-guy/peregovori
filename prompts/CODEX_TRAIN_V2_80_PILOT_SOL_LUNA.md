## Задача только пилота (никакой автоматической полной партии)

Сгенерируй **ровно 8 новых RuntimeCase**: 3 negotiation_only, 3 conflict_only, 2 conflict_then_negotiation. Покрой пять сложностей и обе конфликтные категории MODEL_MANIPULATOR/MODEL_DEFENDER, а также personal/public/mixed. У каждого 3 действительно отличающихся независимых ветви: сильный ход игрока / ошибочное или давление / неожиданное изменение условий. В каждой **4 user↔assistant пары** после сохранённого opening: итого 24 ветви и 96 supervised assistant targets. Sol должен написать **всю историю и все ответы**, а не только начальный кейс. Luna должна дать независимое решение по каждой из 24 ветвей, точные основания и flags; Sol переработать отклонённое; повторно проверить, без self-approval.

Строгий Pydantic RuntimeCase по `web/backend/app/models.py`; верный `teaching` только внутри закрытой структуры кейса, **не в roleplay_messages(), SFT completion или UI**. Устраняем выдуманные имена/числа/продукты/третьих лиц, не подтверждённые сроки и ресурсы, ошибки рода, преждевременные уступки, отсутствие публичного восстановления репутации, >1 вопрос и любые театральные `*ремарки*`. Только произнесённые слова взрослого персонажа. Реалистичные альтернативы, а не вечное бессмысленное сопротивление на impossible.

Проверка Python CPU:
- JSON/Pydantic runtime-1.0, формат `runtime-train-v2.0`, history 9 turns и отделённая branch_id, конвертация `app.roleplay_contract.future_sft`.
- Каждый target соответствует единственной следующей assistant реплике; `opening` входит в prompt, но не supervised label.
- 8 уникальных case_id, 24 уникальных branch records, **ровно 96 SFT examples** при полном acceptance. Все проблемы и причины отказов в отчёте, не заполнять квоту непроверенным.
- Replay `roleplay_messages` через сайт-производный serializer, hash/manifest и no-oracle leakage. Проверять арифметику по отдельному структурному ledger; проверить полномочия и обстоятельства по установленным facts/unknowns. Не подменять semantic review механическим assert.
- Без загрузки весов 8B/14B, без тяжелой модели GPU, без server start.

Сохрани пилот только в новых отдельных путях `dataset/runtime_v2/pilot/` и совместимом `training/derived/runtime-v2/` (если уже существует — не переписывай старые файлы; при конфликте путь выбрать новый), rejected drafts не смешивать с ACCEPTED. Сделай versioned manifest с автором, критиком, фактическими model IDs (если доступны), SHA, принятыми/отклонёнными и списком нарушений. Новые данные не публиковать автоматически в публичный Git: перед публикацией убедись, что нет закрытых мотиваций/частных целей и реальные люди/личная информация отсутствуют; при сомнении приватная ветка/хранилище, в публичной — только sanitized статистика.
