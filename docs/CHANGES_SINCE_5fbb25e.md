- Поля выбора на desktop сужены до 276 px, поле имени до 360 px. Карточки моделей сохранили ширину. Стрелки native select получили отступ 16 px справа.

- Созданы SVG-варианты логотипа и интерактивная галерея. Окончательный набор после следующего коммита: «Сближение», «Диалог», «Следующий ход».

- Панели чата/разбора прокручиваются внутри экрана; поле ответа остаётся доступным. Исправлена компоновка на планшете и мобильном экране.
- Добавлены две проверки восстановления необязательного имени. Обновлены README и запись проверки демо.

## 9b57583 — методология курса и уточнения настройки

- Удалён неподтверждённый лозунг «Спокойный разговор даёт больше возможностей».
- Правило курса `information.open_question` явно передаётся в инструкции персонажа, начальную реплику Generator и примеры Judge: один вопрос, затем ожидание ответа. Judge получил соответствующую рубрику и указание избегать советов вне материалов курса. Детерминированная тестовая начальная реплика также задаёт один вопрос.
- В синтетическом примере оставлен один вопрос; факт поясняет, что Марина — другая сотрудница команды. Generator получает указание пояснять роль и связь человека с ситуацией при первом публичном упоминании.
- Под моделями стоят «Серверная модель» и «Локальная модель». Убрана плашка с техническим ID модели; статус доступности Qwen сохранён.
- Конфликт получил мягкую красную заливку, переговоры остались нейтральными, смешанный режим — градиент от красного к нейтральному.
- «Общий курс» удалён из галереи. В «Диалоге» синяя передняя реплика маскирует заднюю красную, без линий внутри передней. Финальный логотип пока не выбран.
- Для «Другое» поле называется «Ваша тема» и обязательно. Пустое/пробельное значение блокирует старт в UI и отклоняется backend до вызова модели. Тема очищается от внешних пробелов, передаётся генератору и сохраняется для восстановления.
- Добавлены пять проверок темы: отсутствие/None/пустая/пробельная строка и сохранение заполненной темы. README объясняет новое поведение.

## Текущий коммит — копия каталога и подключение будущего домена

- Скачаны HTML, CSS, JS и логотип https://exercises.skillslab.center/games. Сохранены исходная HTML-оболочка, фактическая DOM-разметка, нужные CSS-правила и SHA-256 скачанных файлов в `docs/design_refs/skillslab_games`.
- В `web/catalog/index.html` создана локальная копия страницы. Шесть карточек заменены одной «Линия решения», буква «Л» на акцентном красном фоне #AE432F. Сохранены зелёный фон, затемнение, размеры/радиусы и hover-анимация: подъём 4 px, усиление обводки и тени, 140 мс. `auto-fill` сохраняет исходную ширину карточки при одной игре.
- Логотип, CSS, JS переключения RU/EN и favicon лежат локально. Старый игровой bundle и внешние шрифты не подключены; для открытия каталога не требуется внешний сервер. Перевод касается только каталога, основная игра на русском.
- FastAPI раздаёт `/games`, `/catalog-assets/*` и существующее приложение по `/games/line-decision`. Корневой адрес также открывает приложение. Карточка ведёт в игру; логотип в настройках и «К играм» в чате возвращают в каталог. Скрипт Mac печатает ссылку на каталог.
- HTML и API используют относительные пути на одном origin. Подготовлен `deploy/cloudflared.demo.example.yml`: выбранный hostname → 127.0.0.1:8000, остальные hostname → 404. Inference Qwen остаётся за SSH-туннелем.
- `scripts/start_domain_demo.sh` проверяет заполненность шаблона, ingress и локальный backend перед ручным запуском. Режим `--check` проверяет конфигурацию без запуска. Локальная YAML и папка credentials исключены из Git.
- README содержит минимальную инструкцию после покупки домена: создать именованный туннель, привязать DNS, заполнить три значения, запустить готовый скрипт. DNS и аккаунт сейчас не изменялись, публичный туннель не запускался.
- Добавлены две интеграционные проверки каталога: единственная карточка и все assets на произвольном HTTPS hostname; переход к существующему приложению и API на том же origin без вызова моделей.
