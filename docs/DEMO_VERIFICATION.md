## Реальные внешние соединения

**OpenRouter:** прямой `GET /api/v1/models` с Mac возвращает **HTTP 403**. Через указанный HTTP-прокси `127.0.0.1:10809` — **HTTP 200**, каталог содержит `anthropic/claude-opus-5.5` и `openai/gpt-6-astra`. `scripts/test_openrouter.py` подтверждает каталог и сообщает об отсутствующем ключе. Недоступный локальный proxy port проверен реальным запросом; ошибка выводится без credentials. HTTP/HTTPS proxy configuration, routing, auth/timeout/malformed failure coverage проверены локальными тестами. Настоящий HTTPS-прокси с TLS и password credentials не предоставлялся.

**Intelion:** SSH к предоставленному `root@185.182.108.254` работает. RTX 3090, 24 ГБ; Python 3.10.12, torch 2.11.0+cu128, Transformers 4.57.6, PEFT 0.21.2, bitsandbytes 0.50.2, accelerate 1.15.0. Добавлены отсутствовавшие FastAPI, uvicorn и python-dotenv с их API-зависимостями. Тренировочные скрипты, модели и checkpoint не изменены.

Реальный `/root/peregovori/training/outputs/qlora_v1/adapter` соответствует Qwen3-8B / rank 16 и прошёл проверку LoRA-тензоров. Preflight отказал в загрузке: свободно **3,8 / 23,6 GiB**, оценка для этой конфигурации **10,8–14,8 GiB**. Продолжает работать исходный `train_qlora.py`; его не прерывали.

Inference API действительно запущен на loopback Intelion и проверен через подготовленный SSH-туннель Mac:18080 → Intelion:8001. При занятой GPU `/health` возвращает **HTTP 200, status=error, ready=false, adapter_loaded=false**; chat возвращает **HTTP 503**. Затем только наш проверочный API-процесс и наш SSH-туннель были закрыты. **Это проверка запуска API, туннеля и честного отказа; не успешный Qwen inference.**

## Что требуется для двух настоящих собеседников

1. Локально заполнить `OPENROUTER_API_KEY` в `web/.env`; HTTP-прокси уже настроен для данного Mac. Выполнить `python scripts/test_openrouter.py --game --judge` из `web/.venv` — это проверит реальный Generator, премиального собеседника и добровольный Judge.
2. Дождаться освобождения GPU от текущего эксперимента; выбрать **совместимую пару** базы и завершённого адаптера. Запустить Qwen и SSH-туннель по [README демо](../web/README_DEMO.md).
3. Выполнить `python scripts/test_qwen.py`, затем `python scripts/test_openrouter.py --game --engine lora --judge` и проверить ответы персонажа в игре. Настоящая загрузка, warmup, качество реплик и отсутствие thinking требуют этого GPU smoke-test.
4. Если нужна публичная ссылка — повторить Quick Tunnel на время встречи и открыть её с российского мобильного интернета без VPN/прокси.
