## Basis

Validation выполнена по созданным спецификациям и приложенным материалам курса. Внешние переговорные модели не использовались.

## Checks

1. **Learning outcomes программы:** покрыты блоками conflict, manipulation, preparation/strategy и tactical negotiation в `course_spec.yaml`.
2. **Явно названные приёмы:** из `source_map.md` перенесено **80** отдельных technique objects в `techniques.yaml`.
3. **Source reference для каждого приёма:** PASS.
4. **Внешние концепции:** не добавлялись; упоминания типа Win-Win/эффектов оставлены только там, где они есть в курсе.
5. **Конфликт vs переговоры:** разведены отдельными сущностями и переходами.
6. **Тема на переговоры vs цель на конфликт:** разведены отдельными сущностями и проверочным правилом.
7. **Этапы конфликта:** сохранены 4 этапа с отдельными входами/выходами.
8. **Декодирование vs декомпозиция:** разведены.
9. **Причинная vs критичная проблема:** разведены.
10. **Решение vs результат:** разведены схемой position → solution → result.
11. **Социальная роль vs социальный статус:** разведены.
12. **Противоречия:** собраны в `ambiguities.md` (включая 4 ошибки защиты, 2 базовых приёма, stage-2 transition, SMART и др.).
13. **Runtime subset:** Проверить IDs: negotiation.topic.

## Structural fixes applied

- Нумерация алгоритма подготовки нормализована в структуре как 4 шага, при этом исходная опечатка (3/3) не скрыта и сохранена в `ambiguities.md`.
- Техники получили стабильные machine-readable IDs; оригинальные русские названия сохранены.
- Прямые переходы state machine создавались только там, где есть опора в материалах; спорный stage 2 → negotiation помечен `ambiguous`.
- Пункты `inferred` используются только для структуры схем/датасета, а не как утверждения преподавателя.

## Remaining uncertainties

См. `ambiguities.md`. Критичные для обучения модели:

- точный список «4 ошибок манипулируемого»;
- какие именно два приёма являются «двумя базовыми» для противодействия манипуляциям;
- официальный статус прямого перехода со 2-го этапа к переговорам;
- SMART-анализ: заявлен программой, но операционное содержание в предоставленных материалах не найдено;
- отдельные терминологические/ASR-расхождения: «единственное/надуманное возражение», «приписывание/гиперболизация», SEXI, «итерационность/аттракционность», point L/R.
